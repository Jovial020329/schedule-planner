# Schedule Planner - 日程规划

SillyTavern 第三方扩展插件，为角色和世界生成多天日程安排并注入 AI 上下文。

![SillyTavern](https://img.shields.io/badge/SillyTavern-Extension-blue)

## 功能概览

### 双分支系统
- **👤 个人日程** — 为任意角色（user / char）生成个人日程表
- **🌍 世界事件** — 为故事世界生成公共事件、社会动态、环境变化等

两个分支各自独立的全局指导、生成参数、注入源、提示词设置；共享 API 配置。

### 多角色日程共存
- 可同时保存多个角色的日程表（如 user、角色A、角色B、世界事件）
- 每条日程独立控制是否注入 AI（💉/💤 切换）
- 生成新角色日程不会覆盖已有的其他角色日程

### 事件级别精细控制
- 每个事件左侧有勾选框，控制该事件是否注入 AI
- 避免一次性注入过多事件导致 token 爆炸
- 可按需勾选前几天的事件，聊一段后再切换到后续事件

### 事件编辑
- 每个事件右侧有 ✏️ 编辑按钮
- 可直接修改时间、标题、地点、概述
- 修改后注入内容同步更新

### 交叉注入
- 生成角色 B 的日程时，可选择注入角色 A 的已有日程作为参考
- 实现人物活动轨迹交叉、时间线重叠的合理规划

### 注入源设置
- 角色卡描述
- 用户人设
- 世界书（支持角色绑定 + 全局世界书，条目级多选）
- 其他人物日程表

### API 支持
- **酒馆主模型** — 零配置，直接使用当前酒馆的 API
- **独立 API** — OpenAI 兼容格式，支持自定义 URL/Key/Model，带「获取模型」按钮

### 注入格式
生成的日程以如下格式注入 AI 上下文：
```
[角色名的日程安排]

▣ 第1天 12月25日（星期四）

 - 时间：20:30-22:00
 - 事件：事件标题（标签｜重要程度）
 - 地点：具体地点
 - 概述：详细的情景描写...

 - 时间：22:30-23:30
 - 事件：另一个事件
 - 地点：另一个地点
 - 概述：...
```

## 安装

### 方法一：通过链接安装
1. 打开 SillyTavern，进入 **扩展** > **安装扩展**
2. 输入本仓库地址：
   ```
   https://github.com/你的用户名/schedule-planner
   ```
3. 点击安装，重启酒馆

### 方法二：手动安装
1. 下载本仓库的 ZIP 或克隆：
   ```bash
   git clone https://github.com/你的用户名/schedule-planner.git
   ```
2. 将 `schedule-planner` 文件夹放入 SillyTavern 的：
   ```
   data/default-user/extensions/schedule-planner/
   ```
3. 重启酒馆

## 使用方法

1. 在酒馆侧边栏找到 **📅 日程规划 Schedule Planner** 展开面板
2. 选择分支（👤 个人日程 / 🌍 世界事件）
3. 填写目标角色名（个人日程），配置参数和注入源
4. 点击 **📅 生成**
5. 在「现有日程」列表中点击 💤 切换为 💉 注入 AI
6. 根据需要勾选/取消具体事件，编辑细节

## 提示词自定义

两个分支各有独立的系统提示词和用户提示词，支持以下模板变量：

| 变量 | 说明 |
|------|------|
| `{{targetChar}}` | 目标角色名 |
| `{{numDays}}` | 规划天数 |
| `{{context}}` | 近期聊天记录 |
| `{{charCard}}` | 角色卡描述 |
| `{{userPersona}}` | 用户人设 |
| `{{worldbook}}` | 世界书内容 |
| `{{otherSchedules}}` | 其他角色的已有日程 |
| `{{globalGuide}}` | 全局指导文本 |
